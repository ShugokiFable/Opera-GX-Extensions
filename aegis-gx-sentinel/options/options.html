Secure Relay Router

Routes Opera browser traffic through trusted HTTPS or SOCKS endpoints. Smart mode benchmarks while the computer is idle and selects the lowest-latency healthy route.

Off
Do not paste random “free proxy” lists. Public proxies can log destinations, inject content, steal credentials on HTTP pages, or disappear without warning. Opera’s built-in free VPN or a reputable VPN application is safer. A browser extension cannot create a Windows WireGuard/OpenVPN tunnel.

Format: Name | scheme | host | port | optional username. Supported schemes: https, http, socks5, socks4. Chrome does not support SOCKS authentication.

Session-only proxy credentials

Security boundary
This is a browser defense layer, not endpoint antivirus or perfect anonymity. It cannot hide traffic from applications outside Opera, prevent account-based identification, secure a compromised operating system, or make an untrustworthy relay safe.
