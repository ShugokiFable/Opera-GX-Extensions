# PrismShot GX v1.0.0

Initial public release of PrismShot GX, a dark Manifest V3 video-frame capture extension for Opera GX and Chromium-based browsers.

## Highlights

- Hybrid native source-frame and visible-player capture
- PNG, WebP, and JPEG output
- Native, 2x, 4K, and 8K output modes
- Clipboard and download output
- Configurable filename templates and folders
- Burst capture and approximate frame stepping
- Cross-frame video discovery
- Optional clarity enhancement, letterbox trimming, and watermarking
- On-video controls, popup dashboard, options page, and local history
- No telemetry, advertisements, remote code, or external runtime dependencies

## Release assets

- `PrismShot-GX-v1.0.0.crx`: signed CRX3 package
- `PrismShot-GX-v1.0.0-source.zip`: unpacked extension source
- `PrismShot-GX-v1.0.0.github.bundle`: portable Git repository with `main` and tag `v1.0.0`
- `SHA256SUMS.txt`: SHA-256 integrity hashes
- `release-manifest.json`: machine-readable release metadata
