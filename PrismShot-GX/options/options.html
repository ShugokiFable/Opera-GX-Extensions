Browser and DRM boundaries

Protected video paths can intentionally render black in browser screenshots, and encrypted media may reject canvas extraction. PrismShot does not bypass DRM, HDCP, protected surfaces, site access controls, or browser security boundaries.

Frame stepping uses the best frame-rate estimate exposed by the player. HTML video seeking is keyframe-dependent, so some streams can land near a frame rather than on an exact codec frame.
