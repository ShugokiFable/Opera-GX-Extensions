# Privacy

Nocturne Scrollbars GX does not collect, transmit, sell, or analyze user data.

The extension makes no network requests and includes no remote scripts, analytics SDKs, advertising code, tracking pixels, accounts, or cloud service. Global appearance settings are stored in Chromium's `storage.sync` area so they may follow the user's browser profile when browser sync is enabled. Site-specific rules are stored locally in `storage.local`.

The extension reads the current page hostname only to select the applicable local site profile. It reads the computed background color of the page root/body once when applying adaptive track blending. Page content is not recorded or transmitted.
