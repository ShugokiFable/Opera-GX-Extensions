# OLED Forge GX 1.0.1 installation

## Update an existing unpacked installation

1. Extract `OLEDForgeGX-v1.0.1-source.zip` over a fresh folder.
2. Open `opera://extensions`.
3. Find OLED Forge GX and click **Reload**. If the old folder was moved or removed, choose **Load unpacked** and select the new folder containing `manifest.json`.
4. Refresh open Nexus Mods and YouTube tabs so the new content script runs.

## Packed CRX3

1. Download `OLEDForgeGX-v1.0.1-OperaGX-CRX3.crx`.
2. Open `opera://extensions` and enable **Developer mode**.
3. Drag the CRX onto the extensions page and approve it when Opera GX permits local CRX installation.

Local CRX sideloading can be restricted by the browser or operating-system policy. The unpacked method is the reliable fallback.

## Clean unpacked installation

1. Extract `OLEDForgeGX-v1.0.1-source.zip`.
2. Open `opera://extensions`.
3. Enable **Developer mode**.
4. Choose **Load unpacked** or **Load Extension**.
5. Select the extracted `OLEDForgeGX-1.0.1` folder containing `manifest.json`.
