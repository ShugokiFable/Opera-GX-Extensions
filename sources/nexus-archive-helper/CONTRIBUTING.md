# Contributing

Keep changes focused and testable.

1. Edit source under `src/`, not generated files under `dist/`.
2. Add or update a test for behavior changes.
3. Run `npm run verify` before opening a pull request.
4. Never commit Nexus API keys, `private/signing-key.pem`, or other credentials.
5. Keep Nexus access on documented/official API and user-bound download flows.
