# NebulaGrab

A dark media capture console for Opera GX and Chromium browsers. Detect direct images, video, audio, blobs, HLS, DASH, and numbered CDN fragment families; filter quality; bulk-download; and use the optional localhost companion for resumable disk-cached downloads and Smart Fetch page extraction.

## Highlights

- Concurrent byte-range caching and interrupted-download recovery
- yt-dlp Smart Fetch for supported sites that hide media URLs
- Persistent HLS/DASH fragment caching, SEG-family grouping, byte-range recovery, and best-quality merging
- Optional local browser-cookie access for the user's authorized sessions
- No telemetry or cloud relay
- Adult and non-adult pages treated identically

NebulaGrab does not bypass DRM, protected encryption, paywalls, or access controls.
